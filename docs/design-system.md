### Usage Rules

- Backgrounds should primarily use warm neutral colors.
- Gold should be reserved for important actions, selected states, highlights, streaks, and discovery-related elements.
- Green should only indicate success or growth.
- Most of the UI should rely on neutral colors.
- Accent colors should be used sparingly so they retain visual importance.
- Avoid bright gradients, neon effects, glowing UI, and excessive color usage.

## Typography System

Typography is the primary visual element of Curio.

The interface should rely on elegant typography and generous whitespace rather than decorative UI elements.

## Font Usage Rules

Use Instrument Serif only for moments that deserve emphasis.

Never use it for paragraphs, buttons, navigation, or forms.

Use Geist for everything related to interaction.

The contrast between the editorial serif and the modern sans-serif is a defining part of Curio's identity.

Typography should always feel calm and effortless.

Never overuse bold text.

Use font size and whitespace before increasing font weight.

Limit the interface to three font weights whenever possible:

400

500

600

Avoid using 700+ except for exceptional cases.

# Component Philosophy

Components should be understated.

Content should always be the hero.

Use borders before shadows.

Use whitespace before dividers.

Use typography before icons.

One focal point per screen.

Avoid unnecessary cards.

Avoid visual clutter.

Every screen should feel calm, premium, and thoughtfully designed.
